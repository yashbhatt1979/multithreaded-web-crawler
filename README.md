# Multithreaded Web Crawler

A Java-based multithreaded web crawler built using Spring Boot.

## Tech Stack

* Java 17
* Spring Boot
* Maven
* JSoup
* MySQL
* Git & GitHub

## Features

* Multithreaded web crawling
* Thread-safe URL management
* HTML parsing
* Duplicate URL detection
* MySQL data storage
* REST API

## Project Status

🚧 Under Development

Currently, the initial project structure has been created. Core crawling, concurrency, parsing, and database functionality will be implemented next.
